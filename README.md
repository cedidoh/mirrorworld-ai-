# Mirrorworld AI — starter website

This is a static, mobile-friendly starter interface for Mirrorworld AI.

## What works
- Responsive dark purple interface
- Select and preview two local images
- Basic image type and 10 MB size checks
- Preview-only flow with an honest notice that AI processing is not connected

## What is not implemented
- Real AI face swapping or image generation
- Server-side image upload or processing
- User accounts, billing, or license-key validation

## Publish free with GitHub Pages
1. Create a public GitHub repository named `mirrorworld-ai`.
2. Upload `index.html` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

This is a static frontend. A real AI backend must be deployed separately and connected before offering face-swap processing to clients. Use only images you have permission to edit and clearly label manipulated output.
